# Qlyptra

Небольшая программа для Windows: скачивает трек по ссылке Яндекс Музыки, готовит MP3 и позволяет скопировать его в буфер или сохранить на диск.

Автор: [@wz3k9l](https://t.me/wz3k9l)

[English](README_EN.md)

---

## Как пользоваться

1. В **Настройках** вставьте токен Яндекс Музыки и нажмите «Сохранить токен».
2. На вкладке **«Трек и ссылка»** вставьте ссылку на трек и нажмите **«Найти / скачать»**.
3. Когда трек загрузится, откроется окно:
   - **Копировать MP3** — файл попадёт в буфер обмена, его можно вставить (`Ctrl+V`) в любой мессенджер, который принимает аудиофайлы;
   - **Сохранить** — трек запишется на диск в папку `Tracks` рядом с программой, внутри — подпапка по **первому** исполнителю в названии;
   - **Копировать ссылку** — в буфер попадёт оригинальная ссылка на трек.

После сохранения можно нажать **«Открыть папку»**, чтобы сразу увидеть файл в проводнике.

## Токен

Токен нужен, чтобы загрузчик мог получить трек с вашего аккаунта Яндекс Музыки.

Страница получения:  
https://ym.marshal.dev/token/#implicit-oauth  

Удобный вариант: внизу страницы блок **«Альтернативные способы» → «Вебсайт»**. Следуйте шагам на сайте, скопируйте токен и вставьте его в Qlyptra.

Токен хранится только у Вас на компьютере (в зашифрованном виде для текущей учётной записи Windows). Программа никуда его не отправляет — он используется локально при запросе трека. Не передавайте токен посторонним: он даёт доступ к аккаунту.

## Готовая сборка

Скачайте архив из [Releases]([../..//releases/tag/v1.0.0]), распакуйте **целиком** и запустите `Qlyptra.exe`.

Рядом с `Qlyptra.exe` должна лежать папка `bin` (внутри ffmpeg, окружение загрузчика и прочее) — без неё загрузка не работает. Папку `Tracks` программа создаст сама, когда Вы впервые сохраните трек.

Для запуска готовой сборки **.NET SDK не нужен**. SDK понадобится только если Вы собираете проект из исходников.

---

## Сборка из исходников

Не кладите исходники в `Program Files` — сборка пишет файлы рядом с проектом. Скопируйте репозиторий, например, в `Документы\Qlyptra`.

Нужны Windows x64, [.NET 10 SDK](https://dotnet.microsoft.com/download) и Python 3.9+ (лучше 3.12).

```bat
build.bat
```

Готовая программа появится в папке `release\`.
